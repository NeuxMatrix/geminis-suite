# Web de Géminis Suite

Página estática (sin compilación) en `web/`. El flujo `.github/workflows/web.yml` la publica en GitHub Pages
cada vez que cambia algo de esta carpeta en `main`.

- `index.html`: toda la página, con estilos y scripts dentro.
- `img/`: capturas (WebP) y emblema. `audio/`: demos en MP3.
- Para el subdominio, añade un archivo `CNAME` con el nombre (por ejemplo `geminis.ejemplo.com`).
